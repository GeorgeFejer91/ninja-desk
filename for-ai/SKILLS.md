# Skill routing

Use the smallest relevant installed set. Higher-priority instructions and the user's request win.

| Work | Skill | Rule |
| --- | --- | --- |
| Coding, review, dependencies | `ponytail` | Prefer the smallest complete implementation. |
| Tauri/Rust host and installer | `tauri-rust-developer` | Required for host and packaging changes. |
| Remote browser control and WebRTC | `tauri-browser-remote-control` | Required for transport or authorization changes. |
| Visible HTML/CSS | `uncodixfy`, `uncodixfy-pretext` | Apply restrained design and measured text fit. |
| Current external APIs/docs | `multi-source-web-search` | Verify current primary documentation when facts may change. |
| Greenfield repository/control plane | `for-ai` | Applied at initialization; update only for durable changes. |

Do not claim a skill ran unless it was available and followed. Review external skill instructions before executing them.
