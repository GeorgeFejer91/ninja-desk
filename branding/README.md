# Ninja Desk mark

The original monitor-and-ninja emblem takes broad inspiration from VDO.Ninja's high-contrast ninja theme; it does not use VDO.Ninja's logo or lettering.

- `ninja-desk.svg` is the transparent vector source used by the host and companion.
- `ninja-desk.png` is a transparent 512 px export.
- `ninja-desk-concept.png` is the generated visual concept used for the redraw.

Regenerate app and installer icons with `npm run tauri -- icon branding/ninja-desk.svg -o src-tauri/icons`.
